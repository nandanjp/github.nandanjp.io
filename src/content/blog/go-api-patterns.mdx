Go's standard library is unusually complete for building HTTP services. After a few years of writing Go APIs I've settled on a small set of patterns that I copy into every new service. None of these require third-party frameworks.

## Handler signature

The default `http.HandlerFunc` doesn't return an error, which forces you to either `return` after every error check or swallow errors silently. I prefer a typed handler:

```go
type Handler func(w http.ResponseWriter, r *http.Request) error

func (h Handler) ServeHTTP(w http.ResponseWriter, r *http.Request) {
    if err := h(w, r); err != nil {
        var apiErr *APIError
        if errors.As(err, &apiErr) {
            respondJSON(w, apiErr.Code, map[string]string{"error": apiErr.Message})
            return
        }
        slog.Error("unhandled error", "err", err)
        respondJSON(w, http.StatusInternalServerError, map[string]string{"error": "internal server error"})
    }
}
```

Now handlers can return early with `return fmt.Errorf("decoding body: %w", err)` and the error propagates cleanly to a central place.

## Structured logging with slog

Go 1.21 added `log/slog`. I set it up once at startup:

```go
func setupLogger(env string) {
    var handler slog.Handler
    if env == "production" {
        handler = slog.NewJSONHandler(os.Stdout, &slog.HandlerOptions{
            Level: slog.LevelInfo,
        })
    } else {
        handler = slog.NewTextHandler(os.Stdout, &slog.HandlerOptions{
            Level: slog.LevelDebug,
        })
    }
    slog.SetDefault(slog.New(handler))
}
```

JSON in prod, readable text in dev. Every log line gets a timestamp and level for free. I add request IDs via middleware and pass them through context.

## Request ID middleware

```go
func RequestID(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        id := r.Header.Get("X-Request-ID")
        if id == "" {
            id = uuid.New().String()
        }
        ctx := context.WithValue(r.Context(), ctxKeyRequestID{}, id)
        w.Header().Set("X-Request-ID", id)
        next.ServeHTTP(w, r.WithContext(ctx))
    })
}

func RequestIDFromCtx(ctx context.Context) string {
    id, _ := ctx.Value(ctxKeyRequestID{}).(string)
    return id
}
```

Using an unexported struct type as the context key prevents collisions with keys from other packages — always prefer this over `string` keys.

## Responding with JSON

A tiny helper to keep response code out of handlers:

```go
func respondJSON(w http.ResponseWriter, status int, v any) {
    w.Header().Set("Content-Type", "application/json")
    w.WriteHeader(status)
    if err := json.NewEncoder(w).Encode(v); err != nil {
        slog.Error("encoding response", "err", err)
    }
}
```

## CORS without a library

The `net/http/cors` libraries are fine but adding a dependency for 20 lines of code isn't worth it:

```go
func CORS(origins []string) func(http.Handler) http.Handler {
    allowed := make(map[string]struct{}, len(origins))
    for _, o := range origins {
        allowed[o] = struct{}{}
    }
    return func(next http.Handler) http.Handler {
        return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
            origin := r.Header.Get("Origin")
            if _, ok := allowed[origin]; ok {
                w.Header().Set("Access-Control-Allow-Origin", origin)
                w.Header().Set("Access-Control-Allow-Methods", "GET, POST, PUT, DELETE, OPTIONS")
                w.Header().Set("Access-Control-Allow-Headers", "Content-Type, Authorization")
                w.Header().Set("Vary", "Origin")
            }
            if r.Method == http.MethodOptions {
                w.WriteHeader(http.StatusNoContent)
                return
            }
            next.ServeHTTP(w, r)
        })
    }
}
```

Pass in the allowed origins from config, check the map on every request — O(1) lookup, zero allocations.

---

These five pieces — typed handlers, `slog`, request IDs, a JSON responder, and inline CORS — are enough scaffolding to build a production-ready API without reaching for a framework. Everything else goes in as you need it.
